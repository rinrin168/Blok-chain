Organization login

Certificates you can check against a blockchain record

An organization issues a course certificate as a PDF. A hash of the certificate is stored in a smart contract on the Ethereum Sepolia test network, so anyone with the certificate ID or QR code can look it up and see whether it is valid, expired or revoked.

Verify a certificate Organization login

Check a certificate ID

Type the ID printed on the certificate. You do not need an account.

How it works

  1. An organization signs in and enters the recipient's name, email and course.
  2. The server hashes the certificate data and records the hash in the smart contract.
  3. A PDF with a QR code is generated and emailed to the recipient.
  4. The verify page compares the stored record with the certificate and shows the result, along with the transaction hash and a link to Etherscan.

A certificate can carry an expiry date and can be revoked by the organization that issued it. Revocation is written to the contract as well.
